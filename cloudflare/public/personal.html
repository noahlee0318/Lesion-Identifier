PERSONAL MODEL WORKSPACE

Your photos. Your dataset.

Prepare a model for your own skin. Scale calibration helps measure photos; reviewed labels teach the model.

Photos and labels stay in this browser on this device. Nothing here is sent to the chatbot or Cloudflare. Clearing browser data can erase your work. Export a local backup regularly; avoid cloud-synced folders. Profiles organize data; they are not password-protected accounts.

1 · Choose a local profile

2 · Add a photo

Use consistent lighting, distance, and pose. Include a measured printed marker near the cheek's distance from the camera. This workspace measures scale; it does not verify face alignment or camera geometry.

3 · Measure and label

After setting scale, tap each visible acne spot to mark its center. Adjust diameter before each tap. Label all visible spots, including small ones; leave uncertain photos unreviewed. Do not label moles or the marker. This is annotation, not diagnosis.

A reviewed photo with no marks explicitly means no visible acne spots. Unreviewed photos never train the model. Changes stay drafts until saved.

4 · Prepare personal training

The default split reserves the latest 14 calendar days for testing, 14 earlier days for validation, and 3-day gaps. Plan for at least 35 calendar days with reviewed photos in each block. Enough days does not guarantee enough examples or a good model.

The export contains original photos and annotations. Keep it private and outside the code repository. Each profile currently supports up to 200 MB of original photos so its backup can be restored in this browser tool.

What happens after export?

  1. Run the local Python trainer described in docs/PERSONAL_ML.md.
  2. It learns a small experimental lesion-mask CNN using only this profile and view.
  3. Run held-out evaluation. Review precision, recall, false positives, and missed spots before trusting results.

Browser training and automatic counts are not connected yet. There is no pretrained acne model here. This page never marks a model validated merely because calibration or training completed. Tracking across days is still planned.
