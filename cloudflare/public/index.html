How to use

  1. Create or select your local profile.
  2. For a more consistent setup, practice on 3 different dates: add a photo in Calibration. Print the calibration sheet, measure the marker edge and tap Save draft to record the scale. Multiple photos on one date count as one day.
  3. You can start Daily session anytime. Add regular photos and label spots when ready.

Calibration: 0 / 3 recommended days. Daily session is available now.

Skipping calibration can make measurements and comparisons less accurate. Calibration does not train or validate your model; automatic counts are not available yet.

Start here · print your calibration sheet

This is the marker you need in your photos to measure spot size.

Open printable PDFDownload PDF
  1. Print at 100% / Actual size on matte paper. Turn off “Fit to page.”
  2. Check with a ruler: the outer black square is 30 mm across. The reference line is 100 mm.
  3. Keep the white border around the marker (10 mm on every side). The faint square around it marks that border; do not cut at the black edge.
  4. You do not need the whole page in your photo. Keep the marker flat, fully visible, and near the cheek's distance from the camera.

In the measuring tool below, tap the two ends of the black square's edge, not the faint border. Enter the length you verified with your ruler.

Training progress & backups

Prepare personal training

The default split reserves the latest 14 calendar days for testing, 14 earlier days for validation, and 3-day gaps. Plan for at least 35 calendar days with reviewed photos in each block. Enough days does not guarantee enough examples or a good model.

The export contains original photos and annotations. Keep it private and outside the code repository. Each profile currently supports up to 200 MB of original photos so its backup can be restored in this browser tool.

What happens after export?

  1. Run the local Python trainer described in docs/PERSONAL_ML.md.
  2. It learns a small experimental lesion-mask CNN using only this profile and view.
  3. Run held-out evaluation. Review precision, recall, false positives, and missed spots before trusting results.

Browser training and automatic counts are not connected yet. There is no pretrained acne model here. This page never marks a model validated merely because calibration or training completed. Tracking across days is still planned.
