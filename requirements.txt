# Lesion Atlas - phase 0

# PYTHON 3.12 IS REQUIRED. mediapipe publishes no 3.13 or 3.14 wheels, and the
# machine's default `python` is 3.14 - a venv built from it cannot install
# mediapipe at all. Build the venv from a 3.12 interpreter:
#
#     <python3.12> -m venv .venv
#     .\scripts\install_deps.ps1
#
# torch/torchvision come from the CUDA wheel index, NOT PyPI. Installing them
# with a bare `pip install -r requirements.txt` gets you the CPU build and a
# silently 20x slower LoFTR. Use scripts/install_deps.ps1, or pass the index
# yourself:
#
#     pip install torch==2.11.0 torchvision==0.26.0 \
#         --index-url https://download.pytorch.org/whl/cu128
#
# Verified working on: Windows 11, RTX 4050 Laptop (6 GiB), driver 591.66,
# CUDA 12.8, 2026-09-11.
